# Notebooks

Exploratory analysis, Google Earth Engine experiments, data exploration, and early methodological testing.

Notebooks here are working material and may be incomplete or superseded. Code that proves stable and reusable will be moved into [`src/`](../src/).

Suggested naming: a numeric prefix plus a short description, e.g. `01_landsat_exploration.ipynb`.

Before committing, clear large outputs (e.g. embedded maps or images) to keep the repository small.
